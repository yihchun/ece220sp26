Stack: data structure that holds information, last in first out (LIFO)
Things to do with a stack: push/pop, arithmetic (post-order traversal / RPN),
       match parenthesis, ["pushdown automata" stack+FSM (374)]
Runtime Stack: definition of automatic allocation, reason is because function calls are LIFO
  caller setup: push the arguments from right to left (mnemonic: printf), JSR function
  callee setup: push bookkeeping (rv space, return address (r7), caller frame pointer (br5))
                push local variables, set R5 to bottommost local variable
  [run the callee until it's ready to return]
  callee teardown: save return value, restore r7, restore r5,
                   pop everything except the return value, RET
  caller teardown: pop return value & arguments
Scope: area in which you can use an identifier (global or local [and file, static global])
There are three types of allocation in C:
  static (globals and static local variables) (live forever, data segment)
  automatic allocation (non-static local variables) (live for duration of function, stack)
  dynamic (malloc/free) (live at the pleasure of the programmer, heap)

Recursion: write your comment, function signature, base case, decompose the problem,
           use the force: 1 or more recursive calls (MUST progress to a base case),
           reassemble the answer
Backtracking: Guess the solution, recurse (solve rest of the problem),
              if success, we're done; if fail, guess again
              if you run out of guesses, impossible as posed (return false)
File I/O: fopen, modes ('r', 'w', 'a', '+' modifier), fclose, FILE *,

Dynamic memory allocation: malloc, calloc, realloc, free, sizeof (operator)
